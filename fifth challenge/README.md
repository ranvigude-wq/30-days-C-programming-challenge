ALGORITHM: 
1. Read the operation the user wants to perform
2. Available operations are solving linear equations, solving factorials or solving quadratic equations
3. if choice = 0 end the program
4. if choice = 1 solve linear equation. if roots exists then find the value of the root otherwise infinite solutions or no solution
5. if choice = 2 solve factorial. enter a number from 0 to 12. print value of factorial
6. if choice = 3 solve quadratic equation. if D>0 the roots are real and distinct. if D=0 then roots are real and equal. if D<0 then roots are imaginary.
7. Stop
