Start.
Create a 2D seat array with all seats marked Available.
Display a menu:- View seats
- Reserve a seat
- Cancel a reservation
- Find consecutive seats for a group
- Show occupancy report
- Exit
Get the user’s choice.
If the choice is View seats, display the seat array.
If Reserve a seat, ask for the row and seat number. If it is available, mark it Reserved; otherwise, display “Seat unavailable.”
If Cancel a reservation, ask for the row and seat number. If it is reserved, mark it Available; otherwise, display “No reservation found.”
If Find consecutive seats, ask for the group size. Search each row for enough adjacent available seats. Display the seats found, or report that none are available.
If Show occupancy report, count reserved and available seats, calculate the occupancy percentage, and display the results.
If Exit, stop.
Otherwise, return to the menu.
End
